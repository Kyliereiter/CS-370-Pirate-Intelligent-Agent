# CS 370: Pirate Intelligent Agent

## Project Overview

For this project, I developed an intelligent pirate agent that uses reinforcement learning and neural networks to navigate a maze and find treasure. The goal was to train the agent to make decisions based on its environment and learn which actions would lead to the best outcome.

I was provided with starter code that included the maze environment, supporting functions, and the basic structure for the intelligent agent. My responsibility was to complete the deep Q-learning training algorithm that allowed the pirate to learn through trial and error. By using techniques such as experience replay and exploration versus exploitation, I was able to better understand how an AI agent learns from previous experiences and improves its decision-making over time.

This project gave me hands-on experience with reinforcement learning and helped me understand how neural networks can be used to solve problems without explicitly programming every decision.

## Reflection

### What do computer scientists do and why does it matter?

Computer scientists use technology to solve problems, develop software, and create systems that make everyday tasks easier and more efficient. Their work involves much more than writing code. They also analyze problems, design solutions, test their work, and find ways to improve existing technology.

Throughout this course, I learned how artificial intelligence can approach problems differently from traditional programming. Instead of following a specific set of instructions, an AI system can learn from data and experience. The pirate intelligent agent project helped me see how these concepts can be applied to situations where a system needs to make decisions on its own.

### How do I approach a problem as a computer scientist?

When approaching a problem, I like to break it down into smaller steps so I can better understand what needs to be accomplished. I start by identifying the problem, reviewing the requirements, and figuring out what tools or methods would work best. From there, I develop a solution, test it, and make adjustments when something doesn't work as expected.

Working on this project reminded me that programming involves a lot of trial and error. Training an AI agent requires patience because the results are not always what you expect. I had to understand how different parts of the training process worked together and how changes could affect the agent's performance. This experience helped strengthen my troubleshooting and problem-solving skills.

### What are my ethical responsibilities to the end user and the organization?

As a computer scientist, I believe it is important to develop technology that is safe, reliable, and responsible. This includes protecting personal information, being aware of potential biases, and making sure that software works as intended. Users should be able to trust the technology they are using, and organizations have a responsibility to make sure their systems are secure and dependable.

Artificial intelligence brings additional ethical concerns because AI systems can make mistakes or produce unexpected results. Developers need to understand the limitations of the technology they create and consider how those limitations could affect users. I believe AI should be designed to assist people while maintaining transparency, accountability, and human oversight.
